連線到 Firebase 資料庫

本網頁使用 Firebase Realtime Database 與 Authentication 進行即時資料庫同步與帳戶功能。請貼上您的 Firebase 網頁 SDK 配置物件 (Firebase Config) 以完成連接。

  1. 前往 Firebase 主控台 建立專案。
  2. 在專案中建立一個 Web 應用程式 並複製其 firebaseConfig。
  3. 啟用 Authentication (並啟用 Email/Password 及 匿名 登入)。
  4. 建立 Realtime Database 並將規則設定為允許讀寫（或是部署後進行驗證）。

您的設定檔將僅儲存在您的瀏覽器本地空間 (LocalStorage)，不會上傳至任何第三方伺服器。
